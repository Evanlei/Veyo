# Interface direction

Designed in [Figma](https://www.figma.com/design/gxDTce6luov9uIGO95ehO4?node-id=2-2).
The editable workspace contains 54 descendants, including 35 text layers,
18 layout frames, and one component instance. Typography is Manrope throughout.
The creative specimen is illustrative; production images come from user uploads.

## Foundations

Canvas `#F7F7F2`, surface `#FFFFFF`, ink `#242720`, secondary text `#71766B`,
border `#E3E5DC`, cobalt `#3B4EE8`, pale cobalt `#EEF0FF`, sage `#E8EDDE`.
Use 8 / 12 / 16 / 24 / 32 spacing, 8–12px corners, and fine borders.

## Composition

78px navigation, spacious title row, large creative panel, 350px evidence rail.
Collapse the evidence rail below the canvas on narrow screens. Controls are
semantic buttons and inputs, not clickable decorative text. The image preview
preserves canonical dimensions and maps pointer coordinates to that grid.
